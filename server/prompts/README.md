# prompts/ — 주요 지시문(프롬프트) 기록

AI 정부 실험실 이용가이드(37쪽) 「꼭 해야 할 것」: *사용 목적·주요 프롬프트·생성 수정 내역을 기록(prompts/ 폴더 또는 커밋 메시지)*.
이 폴더가 그 기록이며, 실험실 필수 산출물(⑥ 프롬프트)이다.

## 규칙

- 파일 하나 = 하루 또는 작업 하나. 이름은 `YYYY-MM-DD-주제.md`.
- 지시문은 **요지**를 적는다(전문을 붙일 필요 없음). 단, 결과에 영향이 큰 조건(금지사항·규정 숫자)은 그대로 적는다.
- 반드시 적는 것: ① 목적 ② 쓴 도구(모델) ③ 지시문 요지 ④ 생성된 것(파일·기능) ⑤ 사람이 검토·수정한 것 ⑥ 검증(시험 결과, 실행 결과 숫자)
- 적지 않는 것: 인증키, 회원·직원 개인정보, 알파스 화면·내부 주소·시스템 구조.
- 실측 숫자는 원본(`lab/out/*.csv`)이 따로 있으므로 여기에는 요약만.

## 서식

`템플릿.md`를 복사해서 채운다.
