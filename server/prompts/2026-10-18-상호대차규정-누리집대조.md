# 2026-10-18: 상호대차 판정 규정값을 누리집 안내와 맞춤(상담 비서·원격 판·시민 화면)

## 목적
판정 규칙 일부가 「예시값」으로 남아 있었고(보관 기한·제외 자료·신착), 소요 기간(2~3일)과 미수령 제재(시민 화면 「10일, 예시」, 음성 「열흘간」)가 실제 안내와 달랐다. 10/20(화)부터 상동도서관 창구에서 시험 적용하기 전에, 사서가 이용자에게 읽어 줄 안내문을 부천시립도서관의 공개 안내와 맞춘다.

## 도구
Claude(Claude Code, 모델 claude-opus-5-5)

## 근거
- 부천시립도서관 누리집 「자료검색 > 상호대차서비스 > 부천시립도서관상호대차」(담당 별빛마루도서관, 최종수정일 2026-08-10). 누리집은 외부 자동 열람이 막혀 있어(robots), 담당자가 2026. 10. 18. 19:50 휴대폰 화면 6장을 보내 대조했다.
- 같은 날 자료검색(alpasq) 상세검색 화면 5장: ISBN 검색 칸, 작은도서관 20곳·스마트도서관 3곳, 자료유형(단행본·멀티미디어·전자책).

## 지시문 요지
1. 사용자(19:48): 상호대차 규정은 누리집에 있다 → 화면을 보냄.
2. 대조표와 전·후 고침안 제시(19:5x) → 사용자 「좋아」(19:57).
