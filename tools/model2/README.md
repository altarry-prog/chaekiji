# tools/model2: 공개 모델 실측 도구

- **`run_notebook.py`**: `server/lab/colab_model2.ipynb`(공개 모델 2종 구동 노트북)의 코드 칸을 깃허브 액션 서버에서 차례로 실행합니다. 노트북 코드는 그대로이고, 기록에 적히는 「실행 환경」(코랩 → 깃허브 액션)·실행 기록 주소·파일 이름(`_colab_` → `_actions_`)만 바꾸며 바꾼 곳은 실행 로그에 모두 찍습니다. 2026. 10. 18. 담당자의 행정망 PC에서 코랩이 열리지 않아 사람 손 없이 같은 단계를 실행하려고 만들었습니다. 코랩은 T4 GPU, 깃허브 액션은 CPU라 시간은 환경 차이를 그대로 적습니다.
- **`run_gptoss.py`**: `gpt-oss:20b`를 깃허브 액션 서버(CPU)의 Ollama로 돌려 같은 문의 5건을 처리합니다. 호스트는 엑사원·라마 실측과 같은 `server/hosts/ollama_host.py`입니다.
- **`run_ai_role.py`**: 제목 없이 한 말·맞춤법 틀린 말·외국어·모호한 말 10건을 두 번씩 돌려 도구 호출, 찾은 책(같은 인자로 도구를 다시 불러 ISBN 확인), 판정 갈래, 조회일·누리집 주소, 답의 언어, 되묻기를 기계로 채점합니다.
- **`run_ai_metrics.py`·`report_ai_metrics.py`**: 고정 문의 24건 × 지시문 2종 × 3회로 AI가 맡는 몫 지표(책을 맞게 받은 답의 판정 일치, 다른 책으로 답함, 한국어판 제목으로 바꿔 넘김, 안내문 사실, 답의 언어)를 내고 기록표를 만듭니다. 서버는 snapshot 모드라 정보나루를 부르지 않습니다.
- 실행에 쓴 워크플로 사본은 `tools/workflows/`(`model2.yml`·`model-gptoss.yml`·`ai-role.yml`·`ai-metrics.yml`)에 있습니다.
