# 책이지 — 부천시립도서관 상호대차 음성 AI 에이전트 (시안)

말 한마디로 도서를 찾고, 어느 도서관에서 빌릴 수 있는지 확인하고, 규정에 맞는지
판정한 뒤, 상호대차 신청까지 안내받는 **아이디어 시연 모델**입니다.
"책이 이지(easy)"라는 뜻이며, 앱 설치 없이 브라우저에서 동작하고
홈 화면에 설치(PWA)할 수도 있습니다.

> ⚠️ **운영 중인 서비스가 아닙니다.** 부천시립도서관이 제공하는 서비스가 아니라,
> 공모 제안의 실현가능성을 확인하기 위해 제안자가 만든 시연 모델입니다.
> 신청 흐름은 화면 안에서 완결되며 **실제 상호대차 접수로 이어지지 않습니다.**

부천시립도서관 AI 서비스 도입 TF 검토용 시안입니다.

## 무엇을 하나 — 다섯 단계

1. **말하기** — 마이크를 누르고 일상어로 말한다. 정확한 서명이 아니어도 된다.
2. **도서 확정** — 발화에서 서지 단서를 추출해 정보나루 서지와 대조, ISBN 단위로
   확정하고 근거를 화면에 표시한다.
3. **3단계 탐색** — 자주 가는 도서관 → 관내 16개관 → 전국 순으로 소장·대출
   상태를 찾는다. 자주 가는 도서관에 있으면 신청 대신 서가 방문을 안내한다.
4. **규정 판정** — 수령관 비치·한도 3종 등 상호대차 규정을 자동 검토해
   신청 가능 여부와 사유를 보여준다.
5. **신청 안내** — 수령 도서관·예상 소요가 채워진 신청 요약을 확인 한 번으로
   접수하는 흐름을 시연한다.

## 구현 기능

- 음성 입력·안내 (브라우저 내장 Web Speech, 별도 서버 없음)
- **음성 안내와 화면 전환의 동기화** — 안내 문장이 끝나야 다음 장면으로 넘어가므로,
  듣는 속도로 절차를 따라올 수 있다. 음성을 끄면 기존 속도로 동작한다.
- 10개 언어 음성 인식·안내 전환 (한국어·영어·중국어·일본어·베트남어·태국어·
  러시아어·몽골어·우즈베크어·인도네시아어). 예시 도서는 언어마다 **그 언어 번역판 제목**으로
  말하면 알아듣는다(『소년이 온다』 = Human Acts · 少年来了 · 少年が来る · Bản chất của người ·
  Человеческие поступки · Хөвгүүн ирлээ · Mata Malam / 번역판이 없는 태국어·우즈베크어는 저자 이름과 영어 제목,
  『지구 끝의 온실』은 뜻으로 옮긴 제목). 인식기가 낸 후보 3개를 모두 대조하고, 마이크 안내문도 그 언어로 나온다.
- 접근성: 큰글자 모드, 검색 결과·신청 안내 음성 낭독(TTS)
- **전화 한 통 모드(통화 흐름 시연)** — 헤더의 📞 단추. 스마트폰·홈페이지를 못 다루는
  이용자가 대표번호로 걸었을 때의 대화(인사 → 책 말하기 → 등록 번호 확인 → 판정 낭독 →
  예/아니오 → 접수 → 「책이지가 대신 한 일」)를 목소리만으로 끝까지 재현한다.
  판정·분기는 앱과 같은 논리를 쓰고, 마이크가 없으면 단추·입력으로 답할 수 있다.
  전화로는 무료·취소 가능한 일(조회·관내 신청·예약)만 대신하고, 책바다(실비)는 안내로 넘긴다.
- AI 책큐 연계 시연: 추천 도서 일괄 확인·예약 흐름 (시작·계획 단계 음성 안내 포함)
- 책이지 패스 시연: 범위가 명시된 위임(월 3권·무료 경로만·즉시 해지)에 한 번
  동의하면 매월 추천 도서를 자동으로 준비하는 구독형 자동화.
  **위임 범위를 화면뿐 아니라 음성으로도 고지한다.**
- 설치형 웹(PWA): 홈 화면 설치, 방문 후 오프라인 열람
- **자주 가는 도서관 선택**(v1.5) — 헤더 단추 줄 맨 앞의 📍 단추(언어 단추처럼 현재 도서관 이름을 보여 준다)를 누르면 16개관 중 고를 수 있고,
  수령관·판정·예시 결과·문구가 전부 그 도서관 기준으로 다시 계산되며 새로고침 뒤에도 유지된다(규정 엔진이 상동 전용이 아님을 보이는 장치).
  실제 서비스에서는 회원 정보의 주 이용 도서관이 이 자리를 채운다 — 시연에서는 손으로 고른다.
- **📷 바코드 검색**(v1.5) — 책 뒤표지의 ISBN 바코드를 찍으면 소장 탐색으로 이어진다(BarcodeDetector 지원 기기에서만 단추 표시).
- **등록된 기기(패스키) 체험**(v1.5, ⓘ 안내에서 켜는 선택 기능) — 켜 두면 첫 신청 때 지문·얼굴로 이 기기를 등록하고, 이후 무료 신청은 바로,
  「책이지 패스」 위임 생성은 생체인증을 한 번 더 거친다. 서버 없이 기기 안(WebAuthn 플랫폼 인증기)에서만 동작하며
  확인 시트에는 회원번호를 표시하지 않는다.
- **음성으로 확인**(v1.5) — 음성 안내가 켜져 있으면 신청 확인 시트에서 「네/아니오」로 답해 손 대지 않고 접수까지.
- **기기 내 음성 인식**(v1.5) — 안드로이드 크롬 139+ 등 지원 기기에서는 음성이 기기 안에서 글자로 바뀐다(`processLocally`).
- **WebMCP 도구 등록**(v1.5) — `navigator.modelContext`를 지원하는 브라우저에서는 `search_item`·`check_availability`·`request_service`
  3종을 브라우저 AI에게 도구로 내놓는다. 신청 도구는 이용자 확인 없이는 거부(consequentialHint).

## 정직 고지 — 무엇이 진짜이고 무엇이 시연인가

| 구성요소 | 상태 |
|---|---|
| 화면·음성·다국어·판정 흐름 | **진짜** — 브라우저에서 전부 동작 |
| 소장·대출 데이터 | **실측값 고정 탑재** — 정보나루 Open API로 2026. 8. 18. 부천 16개관 × 도서 4종 = 64건 전수 조회 |
| 상호대차 신청 | **시연** — 실제 접수되지 않음 (도서관리시스템 연동은 운영 단계의 몫) |
| 전화 한 통 모드 | **대화 흐름은 진짜, 전화망은 시연** — 실제 전화는 걸리지 않으며, 회선 연결은 통신 사업자 연동(AI 콜센터 API 또는 070 회선+음성 서버)이 필요한 운영 단계 과제 |
| 대출 상태의 시점 | 정보나루 데이터는 **조회일 전일 기준** — 화면에 상시 고지 |
| 등록된 기기(패스키) | **기기 안에서는 진짜, 서버 검증은 시연** — 생체인증은 실제로 뜨지만 회원 계정과 연결된 서버가 없다. **기본은 꺼짐**: 처음 오는 분에게 지문·얼굴 창을 들이밀지 않기 위해 ⓘ 안내에서 켠 경우에만 첫 신청 때 등록 창이 뜬다 |
| 바코드·기기 내 인식·WebMCP | **지원 기기·브라우저에서만 켜짐** — 미지원 환경에서는 단추·표시가 숨겨진다 |
| 외국어 음성 인식 | **브라우저·기기의 인식 언어 범위에 달려 있다** — 안드로이드 크롬은 10개 언어 대부분을, 아이폰 사파리는 Siri 받아쓰기가 되는 언어만 인식한다. 지원되지 않는 언어는 「이 기기는 ○○어 음성 인식을 지원하지 않아요」로 알리고 글자 입력으로 안내한다. 번역은 시연 웹이 하지 않는다 — 운영 단계에서는 DeepL 공식 MCP 서버 같은 번역 도구를 에이전트 옆에 붙인다(설계도 08절) |

실행 계층의 표준 도구 10종은 별도 저장소의 MCP 참조 서버로 구현되어
적합성 시험 33건을 통과했습니다. 이 시안과 참조 서버가 합쳐져 하나의 제안이 됩니다.
