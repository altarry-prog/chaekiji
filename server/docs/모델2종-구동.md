# 모델 2종 구동: 모델 비종속 입증 절차 (v0.3.4)

이 서버는 MCP(Model Context Protocol) 표준의 stdio 방식이라, 어느 호스트에 연결하든
등록 내용은 똑같다: 명령 `python`(macOS·리눅스는 `python3`), 인자 `server.py` 하나.
그래서 "모델을 바꿔도 같은 도구가 그대로 돈다"는 것을 호스트 2종에서 **같은 지시문·같은 발화**로
실측해 보이면, 특정 모델(LLM)에 묶이지 않는 구조가 입증된다.

v0.3.4의 입증 시나리오는 **상담 비서** 한 흐름이다(접수 없음, 공개 모델에서도 안전).

    발화:   한강 소년이 온다 빌리고 싶어요, 역곡도서관에서 받을게요
    기대:   consult_request(utterance, pickup=역곡) 1회 → ① 판정 「관내 상호대차」 ② 안내문(조회일·전일 기준 포함) ③ 접수 메모

## 호스트 A: 클로드 데스크톱 (상용 모델)

1. `claude_desktop_config.example.json`을 본떠 설정 파일에 서버를 등록하고(모드 `auto`) 재시작한다.
2. 대화창의 「+」(첨부·프롬프트) 메뉴에서 프롬프트 **consult**를 고르고 받을 도서관·언어를 채운다.
3. 위 발화를 넣는다. 도구 호출 1회(`consult_request`)와 세 덩어리 답을 확인하고 화면을 저장한다.
4. (선택) 「채식주의자 있나요?」처럼 픽스처에 없는 책을 넣어 중계 모드(오늘 데이터)로 찾는지 본다(중계가 올라가 있을 때만).

## 호스트 B: 로컬 공개 모델(Ollama)

엑사원은 행정안전부 AI 공통기반이 지원(또는 지원 예정)하는 모델입니다(참가 안내서 10. 21. 변경판의 목록: 젬마·GPT-OSS·엑사원·하이퍼클로바X·솔라 등). 라마는 변경판 목록에서 빠졌지만, 도구 호출을 공식 지원해 두 번째 증빙으로 함께 돌렸습니다.

**설치 없이, 코랩에서(10/16~)**: 아래 주소를 열고 「런타임 → 모두 실행」 한 번이면, 코랩 안에 Ollama를 설치하고 엑사원 3.5 2.4B·라마 3.2 3B를 받아 같은 문의 5건을 같은 지시문으로 처리한 뒤 기록표(`model2_record_colab_….md`)를 만들어 내려받는다(10~15분 추정, T4 GPU 권장). 설치가 막힌 PC라도 인터넷 창으로 코랩이 열리면 된다. 10. 18. 담당자의 행정망 PC에서는 코랩이 열리지 않아, 같은 코드 칸을 깃허브 액션에서 돌렸다(기록은 `lab/out/`). 기록표는 노트북이 실제로 돌린 결과만 담는다.

    https://colab.research.google.com/github/altarry-prog/chaekiji/blob/main/server/lab/colab_model2.ipynb

PC에서 직접 돌릴 때는 아래 절차.

GPU 없는 사무용 PC(RAM 8GB)에서 소형 모델이 돈다. 속도는 입증 대상이 아니다. **같은 도구가 호출되는지**가 핵심이다.

| 순위 | 모델(Ollama 이름) | 받는 크기 | 도구 호출 | 비고 |
|---|---|---|---|---|
| 1 | 엑사원 3.5 2.4B `exaone3.5:2.4b` | 약 1.6GB | json 방식(호스트가 자동 전환) | LG, 한국어가 강함(안내문 품질) |
| 2 | 라마 3.2 3B `llama3.2:3b` | 약 2.0GB | native(Ollama 도구 호출) | 메타, 도구 호출 공식 지원 |
| 3 | 젬마 3 4B `gemma3:4b` | 약 3.3GB | json 방식 | 구글, RAM 여유 있을 때 |

절차:

1. Ollama 설치(https://ollama.com, 윈도우 설치 파일) → 설치가 막히면 GitHub 릴리스의 `ollama-windows-amd64.zip`을 풀어 `ollama.exe serve`로 실행.
2. 모델 받기: `ollama pull exaone3.5:2.4b` (처음 한 번, 몇 분).
3. 서버 폴더에서:

       python hosts/ollama_host.py --model exaone3.5:2.4b --ask "한강 소년이 온다 빌리고 싶어요, 역곡도서관에서 받을게요" --log lab/out/host_log.ndjson

   화면에 `▶ 도구 호출 1: consult_request {...}` 와 `◀ 결과 … route_label=관내 상호대차` 가 찍히고, 이어서 모델의 세 덩어리 답이 나온다.
   `--model llama3.2:3b`로 바꿔 한 번 더 돌린다(native 방식). 대화형으로 쓰려면 `--ask`를 빼면 된다.
4. `lab/out/host_log.ndjson`(도구·인자·소요 시간)과 화면 캡처를 기록표에 옮긴다.

호스트 스크립트는 표준 라이브러리만 쓰며(`hosts/ollama_host.py`), 서버는 호스트 A와 똑같은 `server.py`다. 공공 GitLab의 `ollama-mcp-host`(서울 광진구 류승인, MIT)로도 같은 입증이 가능하다(쓰면 출처를 구동안내서에 밝힌다).
