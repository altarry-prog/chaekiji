## 낱말표(숫자·날짜·주소·명령·코드 이름·화면에 실제로 나오는 「」 이름은 그대로)
- 판정 → 확인·결과(하는 일은 확인, 나온 것은 결과) · 판정 한 줄 → 결과 한 줄 · 판정 도구·규칙 도구 → 확인 도구·규정 프로그램
- 갈래 → 빌리는 방법(바로 이용·관내 상호대차·예약 권장·책바다 안내) · 소장관 → 책이 있는 도서관 · 수령관 → 받을 도서관
- 원격 판 → 인터넷 판(claude.ai에 연결해 쓰는 판) · 설치형 → PC 설치판 · 참조 서버 → 서버 견본
- 중계 → 연결 서버(인증키를 숨기고 정보나루에 대신 묻는 서버, 처음 나올 때 풀이) · 실측 → 측정
- 고정 문의 → 같은 문의 · AI 몫 → AI가 맡는 일 · 권차 → 몇째 권 · 전일 기준 → 하루 전 기준 · 도서관 코드 → 도서관 번호
- 중복 신청 → 이중 신청 · 제외 자료 → 빌려주지 않는 자료 · 수령관 비치 → 받을 도서관에 같은 책이 있음
