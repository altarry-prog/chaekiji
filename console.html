책이지 MCP 콘솔

참조 서버(chaekiji-mcp)와 동일한 도구·규칙·실측 데이터를 브라우저에 옮겨, 에이전트의 도구 호출이 실제로 어떻게 오가는지 눈으로 확인하는 시연 콘솔입니다. 왼쪽 단추를 누르면 오른쪽에 전문(JSON)이 흐르고, 위 멀티탭에서 해당 콘센트에 불이 들어옵니다.

제어판 SCENARIO

규정 설정 CONFIG · 확산의 증명

설정을 바꾸고 ③을 다시 누르면 — 같은 코드·같은 회원인데 판정이 달라집니다. 확산이 "설정 파일을 새로 쓰는 일"인 이유.

도구 호출 로그 JSON-RPC · 요청 → 응답

왼쪽에서 단추를 누르면 여기로 전문이 흐릅니다.

정직 고지 — 이 콘솔은 파이썬 참조 서버 chaekiji-mcp의 규칙 엔진·금고·실측 픽스처(2026. 8. 18. 정보나루 bookExist 64건)를 브라우저에 그대로 이식한 것입니다. 실제 MCP 전송(stdio JSON-RPC)의 검증은 참조 서버의 적합성 시험 12건이 담당하며, 이 화면은 그 동작을 사람이 볼 수 있게 만든 창입니다. 회원은 가상 인물, 대체자료·전국 소장 수는 예시 데이터입니다. · 2026. 8. 부천시립도서관 책이지 프로젝트
