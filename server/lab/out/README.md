# 실측 기록

측정 프로그램이 남긴 원 기록과 그 정리입니다. 원 기록(json·ndjson·csv의 숫자)은 고치지 않았고, 정리 문서(md)와 이 안내는 사람이 썼습니다(직원 측정의 숫자는 직원이 보낸 기록표 그대로). 대출 상태는 정보나루 조회일의 전일 기준이며, 책이지의 어떤 기록도 실제 접수로 이어지지 않았습니다.

- 차례마다 호스트를 고쳤으므로 같은 조건을 되풀이한 결과가 아닙니다(고칠 때마다 나아짐).
- 원 기록: `host_log_actions_…`(도구 호출) · `host_answers_actions_…`(최종 답). 1차는 원 기록만 있습니다.
