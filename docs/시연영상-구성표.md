# 시연영상 구성표

챌린지에 따로 내는 시연영상(2026. 11. 4.에 다시 뽑은 판)의 장면별 구성입니다. 웹에서 바로 보는 720p 영상은 [video/](video/)에 두었고([바로 재생](https://altarry-prog.github.io/chaekiji/docs/video/)), 제출본은 같은 영상의 1080p 파일입니다. 장면마다 「화면」에 화면 설명을, 인용 칸에 화면 글을 적었습니다(자막 파일 [시연영상-자막.srt](시연영상-자막.srt)과 같은 글).

- 길이 4분 57초 · 1920×1080 · 30fps · 음성 해설(AI 합성, MeloTTS)·자막
- 화면에 나오는 대출 상태는 찍은 날의 정보나루 하루 전 기준이고, 시연 화면의 신청은 실제 접수로 이어지지 않습니다.
- 「AI가 맡는 일」 장면은 2026. 10. 30. 실측 기록([ai_role_2026-10-30.md](../server/lab/out/ai_role_2026-10-30.md))을 다시 보여 주는 것이며 claude.ai 화면 캡처가 아닙니다.
- 11. 3. 오후 판에서 바뀐 것: 화면 글·내레이션의 「창구」를 「안내데스크」로, 「맞는 책을 넘긴」을 「맞는 책을 찾은」으로, 「새벽 자료」를 「그날 받은 자료」로. 명령 창 장면을 11. 3. 자료와 지금 답(결과 한 줄 「관내 상호대차 · 안내데스크 확인: 회원 조건」)으로 다시 받음. Solar 상담 창 장면을 11. 4. 다시 녹화(깃허브 액션, 답을 기다린 약 6초만 빨리 감음). 시민 화면은 시연 웹 v1.12.27(첫 화면 아래 사서용 상담 창 링크). 「구현 범위와 검증 결과」의 다음 단계에 시민용 AI 대화 화면(실험실 모델, 보안 검토 뒤). 흐름 1의 claude.ai 화면은 10. 20. 캡처 그대로이며 화면 속 낱말도 그때 것입니다. 음성은 바뀐 장면만 같은 방법(MeloTTS)으로 다시 합성했습니다.
- 영상은 녹화 도구(가지 `tools/video`)로 다시 만들 수 있습니다(`record.py --final`로 녹화한 뒤 `build_video.py`로 묶음).
