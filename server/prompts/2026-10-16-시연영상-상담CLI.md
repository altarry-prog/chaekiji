# 2026-10-16 — 시연영상용 「상담 비서 한 번 부르기」(lab/consult_cli.py)

## 목적
챌린지 시연영상(5분 이내)과 구동안내서에서, 모델 없이 상담 비서 도구(`consult_request`)만 불러 판정·안내문·접수 메모를 보이려고 한다. 지금까지는 MCP 요청 JSON을 손으로 보내야 해서 화면이 읽기 어려웠다.

## 도구
Claude(Claude Code, 모델 claude-opus-5-5)

## 지시문 요지
1. 「5분 시연영상을 만들고 구성과 자막도 만들어라. 기존에 했던 것을 토대로.」(담당자)
2. 시험 결과·기록을 지어내지 않는다. 화면에 나오는 출력은 실제로 돌린 결과만 쓴다.
3. 심사위원이 읽기 쉽게 — 한두 글자로 줄이 바뀌거나 알아보기 힘든 글자(%로 바뀐 주소 등)가 화면을 채우지 않게.

## 생성된 것
- `lab/consult_cli.py` — `server.py`를 띄워 MCP 요청(initialize → tools/call `consult_request`)을 보내고, 돌아온 결과를 사람이 읽는 모양으로 찍는다(▶ 도구 호출 / ◀ 판정·책·근거·안내문·링크·접수 메모). 기본 데이터 모드 `auto`, 인증키 불필요, 접수하지 않음. 안내문 속 누리집 주소는 「(아래 링크)」로 두고 `◀ 링크:` 줄에 한글을 풀어 보인다(같은 주소). 도구가 돌려준 원문은 `--json`.
- `tests/run_relay.py` — 시험을 돌리는 사람의 환경변수(`CHAEKIJI_SNAPSHOT`, `CHAEKIJI_LOCAL_SOURCE`)가 시험 서버에 새어 들지 않게 막음. 영상용 명령을 돌리다 환경변수를 남긴 채 `run.sh`를 돌렸더니 스냅샷 시험이 엉뚱한 파일을 읽어 실패한 일이 있었다. 시험의 판정 기준·건수는 그대로(85건).

## 사람이 검토·수정한 것
- 정확성: 영상에 쓴 출력 세 가지 — 나미야/상동 → 관내 상호대차(꿈여울 등 7곳), 소년이 온다/꿈빛 → 바로 이용, 중계가 끊긴 날 채식주의자 → 소장 확인 불가. 나미야는 원격 판 배포 기록(`relay/last_deploy.json`의 `mcp.consult`)과 갈래·안내문 첫머리가 같음을 확인했고, 나머지 두 갈래는 파이썬 판↔원격 판 대조 시험(18건)이 같은 경우를 덮는다.
- 보안: 키·개인정보·내부 주소 없음. 누리집 링크는 공개 자료검색 화면 주소(설정 `official_search_url`).
- 라이선스: 새 패키지 없음(표준 라이브러리만).
