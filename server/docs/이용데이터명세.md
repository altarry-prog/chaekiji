## 2. 정보나루 Open API: 쓰는 호출과 항목

이용 조건: 회원가입 후 인증키 발급(무료) · 개인 인증키 하루 500회 · 호출 서버 IP 등록 시 하루 30,000건(IP 최대 3개, API·MCP 사용량 합산, 정보나루 MCP 매뉴얼 v20260825) · 출처 표시.

| 호출 | 용도 | 보내는 것 | 받아서 쓰는 항목 |
|---|---|---|---|
| `srchBooks` | 발화 → 도서 확정, 판본 후보, 서지 | `title`(또는 `isbn13`), `exactMatch`, `pageSize` | `isbn13`, `bookname`, `authors`, `publisher`, `publication_year` |
| `libSrchByBook` | 소장 도서관 목록(세부지역·광역) | `isbn`, `region`, `dtl_region`, `pageSize` | `libs[].lib.libCode`, `libName`, `numFound` |
| `bookExist` | 특정 도서관의 소장·대출 가능 여부 | `libCode`, `isbn13` | `result.hasBook`, `result.loanAvailable` (전일 기준) |
| `loanItemSrch` | 측정용 도서 목록 | `startDt`, `dtl_region`/`region`, `pageSize` | `bookname`, `authors`, `isbn13`, `loan_count` |
| `libSrch` | 다른 도시 설정 초안 | `region`, `dtl_region`, `pageSize` | `libCode`, `libName` |

호출 수 구조(도서 1종): `srchBooks` 1 + `libSrchByBook` 1 + `bookExist` × 소장관 수 (+ 관내 대출 가능 소장이 없으면 전국 `libSrchByBook` 1). `lab/measure.py`를 돌리면 `lab/out/measure_*.md`에 남는다(실측 결과는 저장소에 아직 없음). 인터넷 판 상담 1건의 처리 시간 실측은 `lab/out/consult_timing_*.md`.

## 3. 쓰지 않는 것 (명시)

- 도서관리시스템(알파스)·도서관 누리집·통합 SSO에 **접속하지 않는다**. 연동은 `connectors/alpas_stub.py`의 함수 7종 명세(모의)로 대신한다.
- 실제 회원 정보·연락처·대출 이력은 어떤 형태로도 다루지 않는다. 회원은 가상 인물이며, AI 도구 쪽에는 회원 식별자 대신 임시 토큰만 보인다(`vault.py`).
- 정보나루 인증키는 환경변수(`NARU_KEY`)로만 읽는다. 코드·설정 파일·저장소·기록에 쓰지 않는다.
- 정보나루 공식 MCP(2026. 8. 26. 개시)는 서버 안에서 호출하지 않는다(같은 인증키·같은 사용량으로 묶이므로 서버는 Open API를 그대로 쓴다). 공식 MCP는 AI 도구에 나란히 연결하는 용도다(공식 MCP와 나란히 대조하는 시험은 이번 기간에 하지 않음).
