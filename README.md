# 책이지 — 부천시립도서관 상호대차 음성 AI 에이전트 (시안)

말 한마디로 도서를 찾고, 어느 도서관에서 빌릴 수 있는지 확인하고, 규정에 맞는지
판정한 뒤, 상호대차 신청까지 안내받는 **아이디어 시연 모델**입니다.
"책이 이지(easy)"라는 뜻이며, 앱 설치 없이 브라우저에서 동작하고
홈 화면에 설치(PWA)할 수도 있습니다.

> ⚠️ **운영 중인 서비스가 아닙니다.** 부천시립도서관이 제공하는 서비스가 아니라,
> 공모 제안의 실현가능성을 확인하기 위해 제안자가 만든 시연 모델입니다.
> 신청 흐름은 화면 안에서 완결되며 **실제 상호대차 접수로 이어지지 않습니다.**

부천시립도서관 AI 서비스 도입 TF 검토용 시안입니다.

## 무엇을 하나 — 다섯 단계

1. **말하기** — 마이크를 누르고 일상어로 말한다. 정확한 서명이 아니어도 된다.
2. **도서 확정** — 발화에서 서지 단서를 추출해 정보나루 서지와 대조, ISBN 단위로
   확정하고 근거를 화면에 표시한다.
3. **3단계 탐색** — 자주 가는 도서관 → 관내 16개관 → 전국 순으로 소장·대출
   상태를 찾는다. 자주 가는 도서관에 있으면 신청 대신 서가 방문을 안내한다.
4. **규정 판정** — 수령관 비치·한도 3종 등 상호대차 규정을 자동 검토해
   신청 가능 여부와 사유를 보여준다.
5. **신청 안내** — 수령 도서관·예상 소요가 채워진 신청 요약을 확인 한 번으로
   접수하는 흐름을 시연한다.

## 구현 기능

- 음성 입력·안내 (브라우저 내장 Web Speech, 별도 서버 없음)
- **음성 안내와 화면 전환의 동기화** — 안내 문장이 끝나야 다음 장면으로 넘어가므로,
  듣는 속도로 절차를 따라올 수 있다. 음성을 끄면 기존 속도로 동작한다.
- 10개 언어 음성 인식·안내 전환 (한국어·영어·중국어·일본어·베트남어·태국어·
  러시아어·몽골어·우즈베크어·인도네시아어)
- 접근성: 큰글자 모드, 검색 결과·신청 안내 음성 낭독(TTS)
- AI 책큐 연계 시연: 추천 도서 일괄 확인·예약 흐름 (시작·계획 단계 음성 안내 포함)
- 책이지 패스 시연: 범위가 명시된 위임(월 3권·무료 경로만·즉시 해지)에 한 번
  동의하면 매월 추천 도서를 자동으로 준비하는 구독형 자동화.
  **위임 범위를 화면뿐 아니라 음성으로도 고지한다.**
- 설치형 웹(PWA): 홈 화면 설치, 방문 후 오프라인 열람

## 정직 고지 — 무엇이 진짜이고 무엇이 시연인가

| 구성요소 | 상태 |
|---|---|
| 화면·음성·다국어·판정 흐름 | **진짜** — 브라우저에서 전부 동작 |
| 소장·대출 데이터 | **실측값 고정 탑재** — 정보나루 Open API로 2026. 8. 18. 부천 16개관 × 도서 4종 = 64건 전수 조회 |
| 상호대차 신청 | **시연** — 실제 접수되지 않음 (도서관리시스템 연동은 운영 단계의 몫) |
| 대출 상태의 시점 | 정보나루 데이터는 **조회일 전일 기준** — 화면에 상시 고지 |
