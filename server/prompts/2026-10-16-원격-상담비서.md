# 2026-10-16: 원격 상담 비서(claude.ai 커넥터용 MCP) (Claude 생성, 사람 확인)

## 목적

담당자가 쓰는 행정망 PC에는 파이썬과 설치형 클로드 앱이 없다. claude.ai는 인터넷 창으로만 쓴다. 이 상태에서는 지금의 상담 비서(파이썬, stdio)를 클로드에 붙일 수 없다.

그래서 같은 판정을 인터넷 주소 하나로 쓰는 원격 판을 만들었다. 중계 서버(Cloudflare Workers)의 `/mcp` 경로이고, claude.ai 「커스텀 커넥터」에 주소를 넣으면 된다. 심사위원도 설치 없이 연결할 수 있다.

## 지시 요지

- 「파이썬이 필요해? 행망서 돌아갈지 모르겠네」라는 물음에 Claude가 이 방식을 추천했다.
- 담당자는 「다 자동화로 해 줄 수 없을까」라고 했다.

## 바꾼 것

**`relay/mcp.js`(새 파일): MCP Streamable HTTP**
- 요청은 POST JSON-RPC로 받고, 응답은 JSON으로 준다.
- 알림만 오면 202, GET·DELETE는 405를 돌려준다. 묶음 요청을 받는다.
- 규약 판은 2025-06-18, 2025-03-26, 2024-11-05을 맞춰 준다.
- 사용 안내(`instructions`)를 준다.
- 도구는 3종이고 모두 읽기 전용 표시를 붙였다. 프롬프트 `consult`를 준다.
- 파이썬 판에서 옮긴 부분(relay 모드와 같은 문구):
  - naru: `search`·`clean_title`·`bibinfo`·`holdings_local`·`availability_nation`
  - tools: `check_availability`·`_guest_policy`·`consult_request`
  - policy: `check`
- 회원 토큰을 받으면 거절한다. 접수 도구는 없다.

**`relay/build_mcp_data.py`(새 파일)**
- server의 설정·픽스처·지시문·도구 설명을 `relay/mcp_data.js`로 옮긴다.
- `--check`로 원본과 어긋났는지 시험한다.
- 설정에서는 필요한 칸만 옮긴다. SSO 주소 같은 것은 옮기지 않는다.

**`relay/worker.js`**
- `/mcp` 경로를 더했다.
- 세 경로의 공통 처리를 `relayCall`로 묶었다. 캐시는 중계와 함께 쓴다.
- claude.ai 출처에 CORS를 허용했다.

**시험**
- `relay/test_mcp.mjs` 24건: 규약과 판정
- `relay/test_mcp_parity.py` 14건: 파이썬 판과 글자 단위 대조, 모의 중계와 모의 정보나루 사용
- 공통 모의는 `relay/test_naru_mock.mjs`, 시나리오는 `relay/test_mcp_scenarios.json`(시험용 모의 값)
- `tests.yml`이 relay 변경에도 돌게 했다.

**`deploy-relay.yml`**
- 배포 뒤 `/mcp`에서 초기화 → 도구 목록 → 상담 1건을 확인해 기록한다.
- Cloudflare가 막는 프로그램 이름을 확인해 기록한다(`/health`만, 정보나루 호출 없음).

## 검증

- 원격 상담 비서 점검 24건이 통과했다. 중계 점검 19건, 시험 82건도 그대로 통과했다.
- 파이썬 판 대조 14건이 모두 같았다.
  - 대조가 제대로 걸러 내는지도 봤다. 안내문 한 단어를 일부러 바꿨을 때 3건이 실패했다.
- 배포 확인 단계를 로컬에서 끝까지 돌려 봤다. 실제 worker를 띄우고 정보나루는 모의로 두었으며, Cloudflare 이름 차단도 흉내 냈다.
