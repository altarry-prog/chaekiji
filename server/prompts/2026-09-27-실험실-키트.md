# 2026-09-27: 실험실 키트(v0.3.1) 생성

## 목적
실험실 VM 4주 계획(환경 → 실연동·실측 → 확산·저장·감사 → 보고서)에 필요한 코드와 문서를 미리 만들어, VM에서는 실행·기록만 하도록 준비.

## 도구
Claude(Cowork, Claude Fable 5.1): 담당 사서가 대화로 지시, 코드 생성·시험은 Claude 작업 환경(Ubuntu, Python 3.11)에서 수행.

## 지시문 요지
1. 다른 세션이 제안한 4주 계획을 검토하라. 사실과 다른 곳(서버가 떠 있던 적 없다 / 17회→3~8회 실측), 규칙에 걸리는 곳(키를 설정파일에 두기), 빼야 할 것(정적 시연 웹 실연동·동시 요청 부하 시험)을 근거와 함께 짚을 것.
2. 고친 4주 계획대로 1주차부터 4주차 명령 안내서까지 세세하게 만들 것.
3. 조건: 인증키는 환경변수로만(코드·설정·저장소·기록 금지) · 실험실에는 공개·모의 데이터만 · 운영 시스템 접속 금지 · 적합성 시험 33건 수를 바꾸지 말 것(원고 숫자) · 정직 고지(전일 기준·모의) 유지 · 참조 서버 안에서는 정보나루 Open API 사용(공식 MCP는 AI 도구 쪽에서만).
