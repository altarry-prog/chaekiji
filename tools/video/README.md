# 시연영상 만들기 (tools/video)

챌린지 제출용 시연영상(약 5분 이내 mp4, 자막 설명)을 **명령 두 줄로 다시 만드는** 도구입니다. 영상 편집 프로그램을 쓰지 않고, 장면을 브라우저에 차례로 띄워 그 화면을 그대로 받아 적습니다.

```sh
sh tools/video/fetch_fonts.sh            # 처음 한 번 — 글꼴(Pretendard·D2Coding, 둘 다 OFL)
python3 tools/video/capture.py           # 명령 창 출력 다시 받기 — 찍는 날 새벽 자료로 상동 기준 「관내 상호대차」·「바로 이용」 책을 고름 → t1~t4.txt · t_meta.json
python3 tools/video/make_record_clip.py  # 흐름 2 클립 — 저장소의 공개 모델 실측 기록표(server/lab/out/)를 넘겨 보는 화면 → clips/model2.webm
python3 tools/video/record.py            # 녹화(장면마다 내레이션 길이만큼 붙잡음, --mute면 자막만) → tools/video/rec/
python3 tools/video/build_video.py       # → tools/video/out/[시연영상]_경기도 부천시청_책이지_초안.mp4(음성 해설 포함) · .srt · _구성표.md
```

**5판(2026. 10. 26.)** — 첫 장면을 실제 claude.ai 화면으로 열고(창구 질문을 그대로 → 판정·안내문, 1분 안에 「전일 기준·접수는 사서가」), 흐름 2의 자리 표시를 저장소 실측 기록표 화면으로 채웠다. 내레이션은 `narration/script/*.txt`를 고쳐 이 가지에 올리면 `tts.yml`이 MeloTTS(MIT)로 장면마다 세 번 만들고 받아쓰기(faster-whisper)로 가장 또렷한 것을 골라 `narration/audio/script/`에 올린다. 파일 이름 앞 두 자리가 `record.py`의 장면 번호다. 명령 창 장면의 책 이름·관 수는 찍는 날 자료로 바뀌므로 내레이션은 말하지 않고 화면 글이 `t_meta.json` 값을 그대로 쓴다.

**6판(2026. 10. 28., 담당자 승인 「다 승인」)**: 장면을 인포 스타일로 바꿨다. 제목은 과제명과 세 가지 특징 칸, 「왜」는 큰 숫자 세 칸(44개소·320,140권·96.5%)과 신청 전 세 가지, 새 장면 「같은 책을 신청해 보면」(`cmp/compare.html`, 실제 누리집 화면 8장과 시연 화면, 4배속), 흐름은 이용자·AI 모델·규칙 도구·결과를 색으로 나눈 네 칸, 명령 창은 오른쪽 「읽는 법」 칸(판정·근거·안내문·접수 메모), 공개 모델은 숫자 칸(2종·15건·11건), 시민 화면은 단계 표시, 「어디까지 진짜인가」는 지금·다음 두 칸, 끝은 주소와 시연 웹 QR. 맨 앞에는 표지를 둔다(담당자 10. 28. 15:51): 끝 칸과 같은 모양에 QR 대신 찍는 날의 시연 웹 첫 화면을 휴대폰 틀로 크게 넣고, 소리 없이 약 2.4초. 영상의 첫 장이라 재생 전 썸네일로도 보인다. 화면 모양은 `composer.html`의 「인포 스타일 함수」, 장면 순서와 글은 `record.py`. 예시의 받을 곳은 `CHAEKIJI_VIDEO_PICKUP`(capture.py, 기본 상동), 흐름도의 이용자 말은 `CHAEKIJI_VIDEO_SAY`, 「다음 단계」에 덧붙일 줄은 `CHAEKIJI_VIDEO_NEXT`(record.py)로 바꾼다.

필요한 것: Python 3.9+, `pip install playwright`(Chromium), ffmpeg. 인증키·네트워크는 필요 없습니다(글꼴 받을 때만 인터넷).

## 화면에 나오는 것은 모두 실제입니다

| 장면 | 어디서 오나 |
|---|---|
| 명령 창 4개 | 실제로 돌린 명령의 출력 `t1.txt`~`t4.txt`를 그대로 다시 보임(화면에 「실제 실행 결과(기록 재생)」 표시). t1~t3은 `server/lab/consult_cli.py`, t4는 `sh server/run.sh`. 다시 받으려면 `sh tools/video/capture.sh` |
| 표지 | 녹화를 시작하기 직전에 저장소의 `index.html` 첫 화면(390×790)을 받아 휴대폰 틀에 넣음. 받지 못하면 `cmp/app_home.png` |
| 시민 음성 화면 | 저장소의 `index.html`을 별도 브라우저 창(390×790)에 실제로 띄워 조작하고, 그 화면을 휴대폰 틀에 그대로 비춤. 중계 주소는 막아 둠(저장소 자료로 동작) |
| 같은 책을 신청해 보면(비교) | `cmp/compare.html`: 왼쪽은 담당자가 녹화한 실제 누리집 화면 8장(`cmp/real/`, 브라우저 틀을 잘라 내고 아이디·비밀번호를 가림, 자른 방법은 `cmp/real/README.md`), 오른쪽은 시연 웹 실제 화면. 누른 수·시간은 직원 측정의 가운데값 |
| claude.ai 화면 · 코랩 화면 | 담당자가 녹화한 파일(`clips/`)이 있으면 그 자리에서 재생, 없으면 「자리 표시(초안)」 카드 |

※ 시연 웹을 화면 속 화면(iframe)에 넣으면 「미리보기 화면 안에서는 마이크가 막혀 있습니다」가 떠서, 따로 띄워 비추는 방식을 씁니다.

## 자리 표시 두 곳 채우기

1. 녹화(Windows): 브라우저 창을 1280×720 안팎(화면 절반쯤)으로 줄이고 **Win+Alt+R**(게임 바)로 녹화 시작·끝 — 파일은 `동영상\캡처` 폴더에 mp4로 생깁니다. 게임 바가 막힌 PC는 캡처 도구(Snipping Tool)의 「녹화」를 씁니다.
   - claude.ai(30초 안팎): 새 대화 → 「+」 → 커넥터에서 「책이지 상담 비서」 켜기 → 「나미야 잡화점의 기적 빌리고 싶어요, 상동에서 받을게요」 입력 → 도구 허용 → 답이 나올 때까지.
   - 코랩(30초 안팎): 노트북의 마지막 칸(기록표)이 보이는 화면. 「모두 실행」 전체를 찍을 필요는 없고 결과 표가 보이면 됩니다.
2. 바꾸기(소리 없이 VP9로):
   ```sh
   ffmpeg -i claude.mp4 -an -c:v libvpx-vp9 -b:v 0 -crf 32 -vf "scale='min(1920,iw)':-2" tools/video/clips/claude.webm
   ffmpeg -i colab.mp4  -an -c:v libvpx-vp9 -b:v 0 -crf 32 -vf "scale='min(1920,iw)':-2" tools/video/clips/colab.webm
   ```
3. 자막(선택) `clips/claude.json` — 클립 시작부터 몇 초에 어떤 글을 띄울지:
   ```json
   {"title": "claude.ai · 커스텀 커넥터 「책이지 상담 비서」",
    "tag": "실제 화면 녹화(2026. 10. 19.)",
    "caps": [[0, "claude.ai에 같은 문의를 넣습니다", "커넥터를 켜고 이용자의 말을 그대로"],
             [9, "Claude가 consult_request를 부릅니다", "판정은 책이지 도구가 합니다"],
             [20, "판정·안내문·접수 메모", "명령 창에서 본 것과 같은 결과"]]}
   ```
4. 다시 `record.py --final` → `build_video.py`. 「초안」 표시가 빠지고 파일 이름도 `[시연영상]_경기도 부천시청_책이지.mp4`가 됩니다. 5분을 넘으면 `build_video.py`가 알려 줍니다.

## 지금 들어 있는 클립

- `clips/claude.webm`(2026. 10. 18.) — 담당자가 claude.ai에서 커넥터를 실제로 써 본 화면 캡처 한 장을, 도구 사용 줄부터 접수 메모까지 천천히 내려 보이는 26초 정지 화면 클립. 화면에 「실제 화면 캡처(정지 화면)」로 밝힌다. 맨 위 입력 말풍선은 안내 문구가 섞여 들어가 잘라 냈다. 녹화본을 받으면 같은 이름으로 바꾸면 된다.

## 고칠 곳

- 장면 순서·시간·글: `record.py`(장면마다 `# ── n.` 표시). 화면 모양: `composer.html`.
- 명령 창 출력을 다시 받으면(`capture.sh`) 매일 갱신 자료가 바뀌어 관 수·조회일이 달라질 수 있습니다. `record.py`의 해당 자막(「꿈여울 등 7곳」, 「2026. 10. 16. 조회」)도 함께 고칩니다.
- 화면 글은 `text-wrap: balance/pretty`로 한두 글자만 남는 줄을 막습니다. 자막(SRT)은 한 줄 40자 안팎, 한 번에 3줄까지.
